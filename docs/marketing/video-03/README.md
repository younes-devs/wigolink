# Wigolink - video produit 03

Publicite verticale de 25 secondes construite avec une capture reelle du parcours
de publication d'un trajet. Le curseur, les saisies et les clics proviennent du
site local, puis le montage est realise avec Remotion.

## Regenerer la video

1. Lancer `start-demo-api.ps1`.
2. Lancer `start-demo-web.ps1` dans un autre terminal.
3. Executer `npm run capture`.
4. Executer `npm run music` puis `npm run render`.

La sortie finale se trouve dans `output/wigolink-video-03.mp4`.
