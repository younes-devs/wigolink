# Agent Collaboration Guide

Ce repo peut etre modifie par plusieurs agents IA, notamment Codex et Claude.

Avant de travailler:

1. Pull `main`.
2. Lire `docs/ai-workroom/README.md`.
3. Lire `docs/ai-workroom/STATUS.md`.
4. Lire votre inbox:
   - Codex: `docs/ai-workroom/INBOX_CODEX.md`
   - Claude: `docs/ai-workroom/INBOX_CLAUDE.md`
5. Mettre a jour `docs/ai-workroom/TASKS.md` si vous prenez une tache.

Apres le travail:

1. Lancer les validations pertinentes.
2. Mettre a jour `docs/ai-workroom/DONE.md` seulement si le travail est termine.
3. Laisser un message de passage de relais dans l'inbox de l'autre agent si necessaire.
4. Commit et push.

Ne pas utiliser `DONE.md` pour les brouillons, hypotheses ou discussions internes.
